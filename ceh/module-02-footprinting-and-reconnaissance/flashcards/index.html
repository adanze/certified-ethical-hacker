    Flashcards – Module 02¶

    Question

    What is reconnaissance/footprinting?

    Answer

    The preparatory phase where an attacker gathers as much information as possible about a target prior to launching an attack. It is the first step in ethical hacking and results in a blueprint (unique system profile) of the target.

    → Footprinting Concepts
    Question

    What is the difference between passive and active footprinting?

    Answer

    Passive: No direct interaction; hard to detect; uses OSINT, search engines, databases.
    Active: Direct interaction with the target; may be detected; includes DNS interrogation, port scanning, social engineering.

    → Types of Footprinting
    Question

    Name three techniques used in passive footprinting.

    Answer

    1. Open-source Intelligence (OSINT) gathering
    2. Proprietary databases and paid services
    3. Sharing intelligence with partner organizations or industry groups

    → Passive Footprinting
    Question

    Name four techniques used in active footprinting.

    Answer

    1. DNS interrogation
    2. Social engineering
    3. Network/port scanning
    4. User and service enumeration

    → Active Footprinting
    Question

    What three categories of information are gathered during footprinting?

    Answer

    Organization: employee details, locations, web technologies, press releases.
    Network: domains, network blocks, IP addresses, DNS/Whois records.
    System: web server OS, server locations, email addresses, credentials.

    → Information Obtained in Footprinting
    Question

    Name six threats enabled by footprinting.

    Answer

    1. Social Engineering
    2. System and Network Attacks
    3. Information Leakage
    4. Privacy Loss
    5. Corporate Espionage
    6. Business Loss

    → Footprinting Threats
    Question

    Name six techniques used in the footprinting methodology.

    Answer

    1. Search Engines (Google hacking, SHODAN)
    2. Internet Research Services (people search, archive.org, dark web)
    3. Social Networking Sites
    4. Whois Footprinting
    5. DNS Footprinting
    6. Network & Email Footprinting
    + Social Engineering (eavesdropping, shoulder surfing, dumpster diving, impersonation)

    → Footprinting Methodology
    Question

    What is Google hacking?

    Answer

    The use of advanced Google search operators to create complex queries that extract sensitive or hidden information and identify vulnerable targets.

    → Advanced Google Hacking
    Question

    What is the Google Hacking Database (GHDB)?

    Answer

    A curated database of Google hacking queries used to identify sensitive data such as login portals, error messages, vulnerable web apps, and exposed files on public servers.

    → Advanced Google Hacking
    Question

    What is the correct syntax for a Google advanced search operator?

    Answer

    operator:search_term — no space between the operator and the query term.

    → Operator Syntax
    Question

    What is the difference between inurl: and allinurl:?

    Answer

    inurl: requires one specified term in the URL. allinurl: requires all query terms to appear in the URL.

    → Search Operators
    Question

    What does the cache: operator return?

    Answer

    Google's cached (stored) version of a web page, not the current live version. Useful for viewing deleted or changed content.

    → Search Operators
    Question

    What does the site: operator do?

    Answer

    Restricts search results to a specified site or domain.
    Example: games site:certifiedhacker.com

    → Search Operators
    Question

    What does the intext: operator do?

    Answer

    Returns pages containing the specified keyword in the body of the webpage.
    Example: intext:"vpn configuration"

    → Search Operators
    Question

    What is the difference between intitle: and allintitle:?

    Answer

    intitle: requires one term in the page title (other terms match anywhere). allintitle: requires all query terms to appear in the title.
    Example: malware detection intitle:help vs allintitle: detect malware

    → Search Operators
    Question

    What is the difference between inanchor: and allinanchor:?

    Answer

    inanchor: requires one term in the anchor text of inbound links. allinanchor: requires all terms in the anchor text.
    Example: Anti-virus inanchor:Norton

    → Search Operators
    Question

    What does the link: operator do?

    Answer

    Finds pages that contain links pointing to the specified URL.
    Example: link:www.googleguide.com

    → Search Operators
    Question

    What does the related: operator do?

    Answer

    Displays websites that are similar or related to the specified URL.
    Example: related:www.microsoft.com

    → Search Operators
    Question

    What does the info: operator do?

    Answer

    Presents information that Google has about a specific web page.
    Example: info:gothotel.com

    → Search Operators
    Question

    What does the location: operator do?

    Answer

    Returns results for a specific geographic location.
    Example: location: 4 seasons restaurant

    → Search Operators
    Question

    What does the filetype: operator do?

    Answer

    Filters results by file extension.
    Example: jasmine filetype:jpg returns JPG files related to "jasmine."

    → Search Operators
    Question

    What does the source: operator do?

    Answer

    Returns results from a specific source in Google News.
    Example: Malware news source:"Hacker News"

    → Search Operators
    Question

    What does the phonebook: operator do?

    Answer

    Finds residential and business phone numbers for a person or organization.
    Example: phonebook:Sundar Pichai

    → Search Operators
    Question

    What is the difference between before: and after:?

    Answer

    before:YYYY-MM-DD filters results to content published before the date. after:YYYY-MM-DD filters to content published after the date.
    Example: ransomware before:2020-06-29

    → Search Operators
    Question

    Name five types of sensitive data an attacker can find using GHDB queries.

    Answer

    1. Files containing passwords
    2. Login/logon portals
    3. Firewall/IDS logs and configurations
    4. Software version information
    5. Hidden intranet/VPN pages

    → GHDB Extractions
    Question

    What is the GHDB and where is it hosted?

    Answer

    The Google Hacking Database is a subset of the Exploit-DB, hosting Google Dork queries that uncover sensitive information inadvertently exposed on the web.

    → GHDB
    Question

    Name the 14 GHDB categories.

    Answer

    Footholds · Files Containing Usernames · Sensitive Directories · Web Server Detection · Vulnerable Files · Vulnerable Servers · Error Messages · Files Containing Juicy Info · Files Containing Passwords · Sensitive Online Shopping Info · Network or Vulnerability Data · Pages Containing Login Portals · Various Online Devices · Advisories and Vulnerabilities

    → GHDB Categories
    Question

    Name five ways attackers leverage the GHDB.

    Answer

    1. Reconnaissance — gather info on exposed files and devices
    2. Exploiting Misconfigurations — unauthorized access via misconfigured servers
    3. Finding Vulnerable Systems — locate outdated software
    4. Credential Harvesting — extract usernames/passwords
    5. Identifying Open Ports and Services — map entry points

    → How Attackers Leverage the GHDB
    Question

    What is SearchSploit and when is it useful?

    Answer

    A command-line tool for Exploit-DB that enables offline searching of a locally checked-out copy of the exploit repository. Especially useful for assessments on air-gapped or segregated networks without Internet access.

    → SearchSploit
    Question

    What type of information do Google dorks reveal when used for VPN footprinting?

    Answer

    Login portals, VPN key directories, server configurations, and specific VPN product login pages (e.g., Fortinet, Cisco ASA, Zyxel, Citrix Gateway, OpenVPN).

    → VPN Footprinting through GHDB
    Question

    What makes Shodan different from traditional search engines, and what does it index?

    Answer

    Shodan indexes internet-connected devices and services (not web content), exposing open ports, service banners, and device configurations. Used to detect vulnerable devices and networks, including VoIP and VPN systems.

    → SHODAN
    Question

    What footprinting information can Google Advanced Search reveal that a normal search cannot?

    Answer

    Sites linking back to the target — revealing partners, vendors, clients, and affiliations. Enables complex condition-based queries without typing operators.

    → Google Advanced Search
    Question

    What is reverse image search and how do attackers use it?

    Answer

    Uses an image (uploaded or via URL) as the search query to find all online locations of that image. Attackers use it to track profile pictures, photos, and location details of a target.
    Tools: Google, TinEye, Bing, Yahoo, Pinterest.

    → Reverse Image Search
    Question

    What hidden information can attackers extract from videos using analysis tools?

    Answer

    Upload time/date, thumbnails, geolocation metadata, and other embedded data. Tools: YouTube Metadata, YouTube DataViewer, MW Metadata, EZGif, VideoReverser.com.

    → Video Search Engines
    Question

    What is a meta search engine and what advantage does it offer over regular search engines?

    Answer

    A meta search engine has no own index — it simultaneously queries multiple search engines (Google, Bing, Ask.com), aggregates and de-duplicates results. Returns broader results with less effort and hides the user's IP address.
    Examples: Startpage, MetaGer, eTools.ch.

    → Meta Search Engines
    Question

    What do FTP search engines index and what can attackers find through them?

    Answer

    FTP search engines index files on FTP servers — many left unsecured and accessible via browser. Attackers can find business strategies, financial records, employee records, tax documents, and licensed software.
    Examples: NAPALM FTP Indexer, FreewareWeb FTP File Search, Mamont, Globalfilesearch.com.

    → FTP Search Engines
    Question

    What are IoT search engines and what devices can attackers discover through them?

    Answer

    IoT search engines crawl the Internet for publicly accessible IoT devices. Attackers can discover SCADA systems, traffic control systems, CCTV cameras, and industrial/household appliances — many unsecured or using default credentials.
    Examples: Shodan, Censys, ZoomEye.

    → IoT Search Engines
    Question

    What information can attackers obtain about a target IoT device via IoT search engines?

    Answer

    Manufacturer details, geographical location, IP address, hostname, and open ports — used to establish back doors and launch further attacks.

    → IoT Search Engines
    Question

    What kind of information does a company's TLD (public website) expose?

    Answer

    Organizational history, services and products, and contact information. The external URL can be located via search engines such as Google and Bing.

    → TLDs and Sub-domains
    Question

    Why are sub-domains often more vulnerable than the main domain?

    Answer

    Admins often create sub-domains for testing before production deployment. These remain in a testing/insecure state, making them more susceptible to exploitation.

    → TLDs and Sub-domains
    Question

    What critical information can sub-domain enumeration reveal?

    Answer

    Departmental structure, source code and documents on webservers, access control mechanisms (IP, domain, subnet, credentials), and private organizational functions.

    → TLDs and Sub-domains
    Question

    What Google advanced search operator is used to find sub-domains while excluding the main www site?

    Answer

    site:microsoft.com -inurl:www — returns indexed pages under the domain while excluding results containing "www" in the URL.

    → TLDs and Sub-domains
    Question

    What are the three main tools used for sub-domain discovery, and what does each reveal?

    Answer

    Netcraft: sub-domains, web server OS, hosting provider, SSL data.
    DNSdumpster: hosts, sub-domains, IP addresses, DNS servers.
    Pentest-Tools Find Subdomains: sub-domains, IPs, OS, server technology, web platform, page titles.

    → Tools for Sub-domain Discovery
    Question

    How can AI (e.g., ChatGPT) assist in sub-domain discovery?

    Answer

    By generating and executing enumeration commands via prompts. Example prompts: "Discover all subdomains of google.com using dig" or "Use Sublist3r to gather subdomains of eccouncil." AI automates what would otherwise be manual command crafting.

    → TLDs and Sub-domains with AI
    Question

    What does the Sublist3r command sublist3r -d eccouncil.org -o eccouncil_subdomains.txt do?

    Answer

    Enumerates sub-domains of eccouncil.org by searching multiple sources (Bing, Google, Netcraft, VirusTotal, etc.) and saves results to eccouncil_subdomains.txt.

    → Sublist3r Example
    Question

    What is the Internet Archive Wayback Machine and why is it useful to attackers?

    Answer

    archive.org stores snapshots of websites since creation. Attackers can retrieve content removed from the target site — pages, images, audio/video, software — to craft phishing and web application attacks.

    → archive.org
    Question

    What does the Photon flag --wayback do, and how does it differ from --only-urls?

    Answer

    --wayback fetches links from archive.org snapshots of the target.
    --only-urls retrieves archived URLs of the target without full snapshot crawling.

    → archive.org

    Question

    → Job Sites
    Question

    What is the difference between the surface web, deep web, and dark web?

    Answer

    Surface web: indexed, accessible via standard browsers.
    Deep web: unindexed, hidden — government/org databases; accessible via Tor or WWW Virtual Library.
    Dark web: subset of the deep web; fully anonymous; accessible only via specialized tools (Tor Browser, ExoneraTor).

    → Dark Web Footprinting
    Question

    What is the role of Tor Browser in dark web footprinting?

    Answer

    Tor Browser acts as a default VPN, bouncing the user's IP through multiple servers. Attackers use it to access hidden content, unindexed sites, and encrypted dark web databases to gather confidential target data.

    → Tor Browser
    Question

    Name five types of confidential data attackers gather from the dark web.

    Answer

    Credit card details · passport information · ID card details · medical records · social media accounts · Social Security Numbers (SSNs)

    → Dark Web Footprinting
    Question

    What operator pattern is used to construct dark web search queries?

    Answer

    Combine: filetype: (target file type) + site:onion (restrict to .onion) + keyword — or use inurl: / intitle: to narrow by URL or page title.
    Example: filetype:sql site:onion dump finds database dumps; intitle:"login credentials" filetype:docx finds credential documents.

    → Dark Web Search Queries
    Question

    What is OS fingerprinting and which three tools are used for it?

    Answer

    OS fingerprinting is the technique of detecting the operating system running at the target. Tools: Netcraft (site OS lookup), Shodan (connected devices and known CVEs), Censys (full internet-exposed asset inventory).

    → Determining the OS
    Question

    What unique capability does Shodan offer beyond OS detection?

    Answer

    Shodan searches for known vulnerabilities and exploits across Exploit-DB, Metasploit, CVE, OSVDB, and Packetstorm in a single interface, alongside device discovery by city, country, hostname, and IP.

    → Determining the OS
    Question

    What is competitive intelligence gathering and how does it differ from espionage?

    Answer

    CI gathering is the process of identifying, gathering, analyzing, verifying, and using competitor information from public sources. It is non-interfering, subtle, and legal — unlike industrial espionage or direct IP theft via hacking.

    → Competitive Intelligence
    Question

    What is the difference between the direct and indirect approach in CI gathering?

    Answer

    Direct: primary source; trade shows, social engineering of employees/customers.
    Indirect: online resources; company websites, job ads, press releases, patents, financial filings, legal databases, search engines.

    → CI Approaches
    Question

    What four questions does competitive intelligence help answer about a target company?

    Answer

    1. When did it begin? — history and establishment date
    2. How did it develop? — strategies, CRM, advertising
    3. Who leads it? — key decision-makers
    4. Where is it located? — branches and operations

    → What CI Helps Determine
    Question

    What is EDGAR and what kind of information does it provide?

    Answer

    EDGAR (Electronic Data Gathering, Analysis, and Retrieval) is the SEC's system for automated collection and dissemination of mandatory corporate filings. It provides time-sensitive corporate information to improve transparency in the securities market.

    → CI Information Resources
    Question

    LexisNexis: Legal, public records, and compliance data for risk/fraud/identity.
    Factiva: 33,000+ licensed sources — news, publications, newswires in 28 languages.

    → CI Information Resources
    Question

    Which CI tool is used to research competitor patent and trademark registrations?

    → CI Company Plans
    Question

    SERanking: Traffic dynamics, keyword semantics, PPC competitor research.

    Question

    What are alerting services and how do attackers use them for footprinting?

    Answer

    Content monitoring services that deliver automated notifications (email/SMS) when new content matches a defined search term. Attackers use them to passively track mentions of the target's name, members, website, and projects in real time.
    Tools: Google Alerts, X Alerts, Giga Alerts.

    Question

    What is Online Reputation Management (ORM) and how do attackers exploit it?

    Answer

    ORM monitors and improves a company's online reputation. The transparency it creates lets attackers collect genuine, up-to-date information — search rankings, mentions, social news, and online conversations about the target.
    Tools: Mention, ReviewPush, Reputology.

    → Other Techniques
    Question

    What employee information can attackers gather from groups, forums, and blogs?

    Answer

    Full name, workplace/residence, phone numbers, personal and organizational email addresses, and photos (residence, workplace, awards). Attackers search by FQDNs, IP addresses, or usernames and may register with fake profiles in Google Groups or LinkedIn Groups.

    → Other Techniques
    Question

    What sensitive data can be found in public source-code repositories, and what tool is used to discover them?

    Answer

    Configuration files, private SSH and SSL keys, source-code files, dynamic libraries, and software tools. Combined with active footprinting, this enables spear phishing and infrastructure attacks.
    Sites: GitHub, GitLab, SourceForge, BitBucket.
    Tool: Recon-ng — a full-featured web reconnaissance framework.

    → Other Techniques
    Question

    How is theHarvester used to gather information from LinkedIn, and what does each flag mean?

    Answer

    Command: theHarvester -d microsoft -l 200 -b linkedin
    -d = target domain/company name · -l = number of results · -b = data source (linkedin).
    Returns employee names and job titles for use in social engineering and targeted attacks.

    Question

    What is the key difference between footprinting through social networking sites and footprinting through social engineering?

    Answer

    SNS footprinting: passively collects information users have already posted publicly — no deception, no interaction required.
    Social engineering footprinting: actively tricks people into revealing information through direct manipulation.

    → SNS vs. Social Engineering Footprinting
    Question

    What search inputs can attackers use when searching for people on social networking sites, and what makes it anonymous?

    Answer

    Attackers search by name, email address, or physical address. Many platforms allow searching without registration, making people searches easy and anonymous. Some sites also reveal whether an account is active.

    → People Search on SNS
    Question

    What categories of information can attackers collect from social networking sites like Facebook, LinkedIn, and Twitter?

    Answer

    Personal: name, position, organization, location, educational qualifications.
    Professional/contact: company, phone number, email, photos, videos.
    Behavioral (Twitter): advice, news, opinions, rumors, facts, announcements, and event details.

    → Types of Information Gathered
    Question

    How do attackers harvest email lists from a target domain using theHarvester, and what is the purpose of the -f flag?

    Command: theHarvester -d microsoft.com -l 200 -b baidu -f Microsoft_emails.xml
    -d = target domain · -l = result limit · -b = search engine source · -f = output file name (XML format).
    Harvested emails are used for social engineering and brute-force attacks.

    Question

    How can AI assist in email harvesting footprinting, and what is an example prompt?

AI automates command crafting, lowering the attacker's skill requirement.

    → Harvesting Email Lists with AI

Attackers use it to track shared content related to a target domain and collect social media accounts, URLs, and email addresses for phishing and social engineering.

    --output recon2 saves all discovered profile URLs to a file named recon2.

    → SNS Footprinting with AI
    Question

    What is Whois and on which port does it operate?

    Answer

    Whois is a query and response protocol for querying databases that store registered users or assignees of an Internet resource (domain name, IP address block, or autonomous system). It listens on port 43 (TCP).

    → Whois Lookup
    Question

    What are the three Whois data models?

    Answer

    Thick Whois (Distributed): stores complete Whois info from all registrars.
    Thin Whois (Centralized): stores only the registrar's Whois server name; full details held by that server.
    Decentralized Whois: stores complete info with multiple independent entities managing the database.

    → Whois Data Models
    Question

    Name five pieces of information a Whois query returns.

    Answer

    Domain name details · domain registrar · contact details of the domain owner · domain name servers · NetRange · creation date · expiry records · last updated record · domain status · IP address information

    → What a Whois Query Returns
    Question

    How do attackers use information obtained from a Whois lookup?

    Answer

    1. Create a map of the organization's network
    2. Mislead domain owners with social engineering
    3. Obtain internal details of the network

    → How Attackers Use Whois Data
    Question

    Name the five Regional Internet Registries (RIRs) and their regions.

    Answer

    ARIN – North America · AFRINIC – Africa · APNIC – Asia-Pacific · RIPE NCC – Europe/Middle East · LACNIC – Latin America & Caribbean

    → Regional Internet Registries
    Question

    What makes Batch IP Converter useful for Whois footprinting?

    Answer

    It provides country, state/province, city, phone, fax, network provider, administrator, and technical-support contact info for an IP address, hostname, or domain. It supports Internationalized Domain Names (IDNs) and IPv6.

    → Whois Lookup Tools
    Question

    What types of information does IP geolocation provide about a target?

    Answer

    Country, region/state, city, latitude/longitude, ZIP/postal code, time zone, connection speed, ISP (hosting company), domain name, IDD country code, area code, weather station code and name, mobile carrier, and elevation.

    → Finding IP Geolocation Information
    Question

    How do attackers leverage IP geolocation data, and which tools provide it?

    Answer

    Attackers use it to launch social engineering attacks (spamming, phishing), perform surveillance and non-technical attacks (dumpster diving, hoaxing), set up compromised servers near the victim, or deploy location-specific malware.
    Tools: IP2Location, IP Location Finder, IP Address Geographical Location Finder.

    → IP Geolocation Lookup Tools
    Question

    What is DNS footprinting and where does it fall in the footprinting methodology?

    Answer

    DNS footprinting is the phase immediately following Whois footprinting. Attackers query DNS infrastructure to collect information about DNS servers, DNS records, and server types used by the target organization.

    → DNS Footprinting
    Question

    What attacker value does DNS footprinting provide?

    Answer

    It allows attackers to identify hosts connected to the target network, forming the basis for further exploitation of the target organization.

    → DNS Footprinting – Purpose
    Question

    What are the three key techniques used in DNS footprinting?

    Answer

    DNS record extraction: querying for various record types to enumerate infrastructure.
    Reverse DNS lookups: resolving IPs back to hostnames to map the network.
    DNS interrogation tools: automated tools that systematically query DNS servers at scale.

    → DNS Footprinting – Key Techniques
    Question

    What does DNS zone data contain, and how do attackers use it?

    Answer

    DNS zone data includes DNS domain names, computer names, IP addresses, and more. Attackers use it to determine key hosts in the network and then perform social engineering attacks to gather even more information.

    → Extracting DNS Information
    Question

    What DNS record type maps an IP address to a hostname, and which maps a hostname to an IPv6 address?

    Answer

    PTR maps an IP address to a hostname (reverse lookup).
    AAAA maps a hostname to an IPv6 address.

    → DNS Record Types
    Question

    Question

    What protocol and IP header field does traceroute use, and what four types of information does it reveal?

    Answer

    Uses ICMP protocol and the TTL field. Reveals: number of hops, round-trip time (RTT) between routers, router names and network affiliation, and geographic locations of intermediate hops.

    → Traceroute
    Question

    How does the TTL mechanism work in traceroute?

    Answer

    Each router decrements TTL by 1. When TTL=0, the router discards the packet and returns an ICMP error message to the source. Traceroute starts with TTL=1 and increments by 1 per probe, recording each hop until the destination responds with an ICMP reply.

    → How TTL Works
    Question

    What are the three traceroute types, their protocols, and their commands?

    Answer

    ICMP (Windows default): tracert <target>
    TCP (Layer 4, Linux): sudo tcptraceroute <target>
    UDP (Linux default): traceroute <target>
    TCP/UDP are used when ICMP is blocked by network devices.

    What is eavesdropping and what forms of communication can it target?

    Answer

    Question

    What is shoulder surfing and what types of data does it target?

    Answer

    Secretly observing the target to capture critical information. The attacker stands behind the victim and watches keystrokes or screen activity. Effective for capturing passwords, PINs, security codes, account numbers, and credit card information. Easiest to perform in crowded places.

    → Shoulder Surfing
    Question

    What is dumpster diving (trashing) and what sources does an attacker target?

    Answer

    Rummaging through garbage to find sensitive information. Sources: trash bins, printer waste bins, sticky notes at desks, and ATM trash bins. Yields phone bills, contact info, financial info, operations-related info, and printouts of source code or sensitive data.

    Answer

    What are footprinting countermeasures?

    Answer

    Measures or actions taken to prevent or offset information disclosure to potential attackers. They span web infrastructure, published content, personnel behavior, network protocols, and physical location.

    → Footprinting Countermeasures
    Question

    Name four web and DNS hardening countermeasures against footprinting.

    Answer

    1. Configure web servers and IIS to avoid information leakage and banner grabbing.
    2. Disable directory listings in web servers.
    3. Use split DNS and restrict zone transfer to authorized servers only.
    4. Avoid domain-level cross-linking for critical assets.

    → Web and DNS Hardening
    Question

    What publication and information control countermeasures prevent footprinting?

    Answer

    Limit website content; avoid disclosing critical info in press releases and annual reports; prevent search engine caching; use anonymous registration services; request archive.org to remove site history; keep the domain name profile private; place critical documents offline; do not display sensitive plans on notice boards.

    → Information and Publication Control
    Question

    What two network-level countermeasures hide an organization's IP address from footprinters?

    Answer

    1. Implement a VPN to mask the real IP address.
    2. Keep the server behind a secure proxy.

    Question

    Question

    Name four personnel and awareness countermeasures against footprinting.

    Answer

    1. Restrict employee access to social networking sites from the organization's network.
    2. Educate employees to use pseudonyms on blogs, groups, and forums.
    3. Conduct periodic security awareness training about social engineering tricks.
    4. Train employees to thwart social engineering attacks.
