  <div class="flashcard-inner">
    <div class="flashcard-front">
      <span class="flashcard-label">Question</span>
      <p>What is reconnaissance/footprinting?</p>
    </div>
    <div class="flashcard-back">
      <span class="flashcard-label">Answer</span>
      <p>The preparatory phase where an attacker gathers as much information as possible about a target prior to launching an attack. It is the first step in ethical hacking and results in a blueprint (unique system profile) of the target.</p>
      <a class="flashcard-link" href="../footprinting-concepts/#definition">&#x2192; Footprinting Concepts</a>
    </div>
  </div>
</div>

<div class="flashcard exam-critical">
  <div class="flashcard-inner">
    <div class="flashcard-front">
      <span class="flashcard-label">Question</span>
      <p>What is the difference between passive and active footprinting?</p>
    </div>
    <div class="flashcard-back">
      <span class="flashcard-label">Answer</span>
      <p><strong>Passive:</strong> No direct interaction; hard to detect; uses OSINT, search engines, databases.<br><strong>Active:</strong> Direct interaction with the target; may be detected; includes DNS interrogation, port scanning, social engineering.</p>
      <a class="flashcard-link" href="../footprinting-concepts/#types-of-footprinting">&#x2192; Types of Footprinting</a>
    </div>
  </div>
</div>
