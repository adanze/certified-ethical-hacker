# Module 03 – Scanning Networks

After identifying the target and performing initial reconnaissance, attackers begin to search for an entry point into the target system. They determine whether target systems are active or inactive to reduce time spent on scanning. Scanning itself is not the actual intrusion but an extended form of reconnaissance in which the attacker learns more about the target — including OSs, services, and configuration lapses — to select strategies for attacking the target system or network.

This module starts with an overview of network scanning and provides insights into various host discovery techniques for checking live and active systems. It also covers port and service discovery techniques, OS discovery techniques, techniques for scanning beyond IDS and firewalls, and an overview of drawing network diagrams.
