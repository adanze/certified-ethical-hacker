# Hacking Concepts

Understanding hacker terminology and methodology is essential for defending systems effectively.

## Hacker Classes

| Type | Authorization | Intent |
|------|--------------|--------|
| **White Hat** | Yes | Improve security |
| **Black Hat** | No | Personal gain / damage |
| **Grey Hat** | Sometimes | Mixed motives |
| **Script Kiddie** | No | Uses existing tools, no deep knowledge |
| **Hacktivist** | No | Ideological or political goals |

## Phases of Hacking

1. **Reconnaissance** — passive and active information gathering
2. **Scanning** — port scanning, vulnerability scanning, network mapping
3. **Gaining Access** — exploiting vulnerabilities to enter the system
4. **Maintaining Access** — backdoors, rootkits, persistence mechanisms
5. **Clearing Tracks** — deleting logs, hiding evidence of the intrusion

## Types of Hacking

- **Ethical hacking** — authorized testing to identify and remediate vulnerabilities
- **Penetration testing** — simulated attack under a defined scope and rules of engagement
- **Red teaming** — adversary simulation without predefined limitations

## Key Terminology

- **Vulnerability** — a weakness that can be exploited
- **Exploit** — code or technique that takes advantage of a vulnerability
- **Payload** — the part of an exploit that performs the intended action
- **Zero-day** — a vulnerability with no available patch
