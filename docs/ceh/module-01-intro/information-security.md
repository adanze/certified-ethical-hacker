# Information Security

Information security protects data from unauthorized access, modification, or destruction.

## CIA Triad

The three pillars every security control maps back to:

| Principle | Goal | Example |
|-----------|------|---------|
| **Confidentiality** | Only authorized parties can read data | Encryption, access controls |
| **Integrity** | Data is accurate and unaltered | Hashing, digital signatures |
| **Availability** | Systems are accessible when needed | Redundancy, DDoS mitigation |

## Types of Attacks

- **Active attacks** — modify or disrupt data in transit (e.g. session hijacking, DoS)
- **Passive attacks** — observe without altering (e.g. eavesdropping, traffic analysis)
- **Insider threats** — originate from within the organization

## Security Controls

Controls are categorized by function:

- **Preventive** — stop an attack before it happens (firewalls, MFA)
- **Detective** — identify an attack in progress (IDS, log monitoring)
- **Corrective** — minimize damage after an attack (backups, incident response)

## Defense in Depth

Layering multiple controls so that bypassing one layer does not compromise the entire system. No single control is relied upon exclusively.
